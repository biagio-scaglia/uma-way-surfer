# Uma Way Surfer

Fangame non commerciale: un endless runner 3D a tre corsie che gira nel browser.

## Avvio

Serve Node.js. Il gioco va aperto tramite il server di sviluppo: un doppio clic su `index.html` non basta.

```
npm install
npm run dev
```

**Comandi:** frecce o WASD (spazio salta), swipe su telefono, Esc o P per la pausa.
